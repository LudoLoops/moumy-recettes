1. Faire chauffer le four réglé sur thermostat 4 (170 °C) 

2. Beurrer les tranches de pain. Couper les abricots en deux ; retirer les noyaux. 

3. Poser 3 demi abricots sur chaque tranche de pain ; saupoudrer abondamment de sucre

4. Poser dans un plat à four à peine beurré placé en position haute dans le four. Faire cuire pendant trois quarts d’heure 

5. Server chaud, de préférence
