1. Faire chauffer le four réglé sur thermostat 4 (170 °C). Beurrer les tranches de pain. Couper les abricots en deux ; retirer les noyaux. Poser 3 demi abricots sur chaque tranche de pain ; saupoudrer abondamment de sucre, poser dans un plat à four à peine beurré placé en position haute dans le four. Faire cuire pendant trois quarts d’heure. Server chaud, de préférence.
