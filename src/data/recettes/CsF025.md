1. Mettre les cornichons dans une passoire avec une poignée de gros sel

2. Les faire sauter de temps en temps

3. Les laisser dégorger pendant au moins six heures

4. Le essuyer un par un avec un torchon de grosse toile

5. Les placer dans un bocal. Ajouter les aromates et les petits oignons épluchés. Remplir à ras bord avec le vinaigre

6. Attendre quinze jours pour consommer

7. Vous pouvez préparer les petits oignons de la même manière

8. Les éplucher. Pour éviter de pleurer, les rouler dans une assiette où vous aurez mis un peu de vinaigre. Les faire dégorger pendant toute une nuit avec une poignée de sel avant de les mettre au vinaigre
